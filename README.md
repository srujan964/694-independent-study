# An Independent Study on Data Compression

My collection of notes and report material for an Independent Study
course looking into data compression.

The assets directory contains a couple of image files used in the
report.

## Requirements

All the notes are in plain Markdown, with some minor syntactical
differences as they were originally imported from Logseq.

[Typst](https://github.com/typst/typst) is used to compile the report 
source into PDFs:
```
typst v0.14.2
```

## Usage

```
typst compile study-report.typ
```
